# 🚗 ADS Sistemas | Catálogo de Veículos

Projeto desenvolvido em sala de aula para praticar **HTML**, **CSS** e os primeiros passos em **JavaScript**.

A página apresenta uma empresa fictícia de veículos elétricos, com cabeçalho de destaque, barra de busca e um catálogo de modelos em cards.

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, variáveis CSS e media queries)
- JavaScript

## ✨ Funcionalidades

- Layout responsivo, que se adapta a telas menores
- Menu ☰ para celular
- Saudação no título conforme a hora do dia (Bom dia, Boa tarde, Boa noite)
- Cards do catálogo gerados a partir de uma lista de dados
- Busca de veículos em tempo real
- Marcar veículos como favoritos ❤️
- Ano do rodapé atualizado automaticamente

## 📚 Conceitos de JavaScript trabalhados

O arquivo `script.js` está dividido em etapas, cada uma apresentando um conceito novo:

| Etapa | Conceito | Onde aparece |
|---|---|---|
| 1 | Eventos e `alert` | Botão Login |
| 2 | Variáveis e alteração do DOM | Ano do rodapé |
| 3 | Condicionais (`if / else`) | Saudação no cabeçalho |
| 4 | Classes CSS via JavaScript | Menu no celular |
| 5 | Arrays, objetos e laços | Cards do catálogo |
| 6 | Strings e lógica de busca | Barra de busca |
| Extra | Revisão de eventos e `classList` | Favoritar um card |

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é preciso instalar nada.

## 📁 Estrutura

